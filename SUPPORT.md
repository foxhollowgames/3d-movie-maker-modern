# Support

Report distribution problems at https://github.com/foxhollowgames/3d-movie-maker-modern/issues.
Include the release version, operating system, CPU architecture, and steps to reproduce the problem.
Press Ctrl-Shift-I in the application to inspect its version.

This is a community project without commercial support or a Microsoft support commitment.
Credit for the application port belongs to 3DMMEx and 3DMMForever contributors.
